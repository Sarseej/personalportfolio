# Information architecture

| State | Hash | Physical destination | Reading interface |
| --- | --- | --- | --- |
| Home | #home | Entrance composition | Identity, positioning, direct professional routes |
| Projects | #projects | Main monitor | Four-project navigator, problem, role, approach, evidence, system walkthrough, technical expansion and limitations |
| Career | #career | Secondary monitor | Chronological graph with education, experience and project categories; concise selected-node explanation |
| CV | #cv | Desk paper | Conventional education, experience, projects, skills and contact document |

Contact is a direct email link. GitHub uses the verified public profile. The separate /resume static route presents the same CV document for printing. No public-safe PDF has been supplied, so there is no Download CV action.

Physical hitboxes, their HTML labels, footer destinations and persistent navigation call the same state transition. Browser Back/Forward and direct hash entry work without server routes. Back and Escape return to Home. Project selection and timeline details are local to their destination.

All reading content is semantic HTML. Static WebGL-failure mode exposes the same destinations; no-JavaScript markup supplies project, career and CV sections. Mobile uses large navigation and full-screen reading rather than precision selection.

Tutoring has no room hotspot or standalone presentation. The later correction restores the full Mathematics Tutor → Senior Mathematics Tutor Career node for September 2023–May 2026. A promotion marker, subjects, mentoring and study materials explain analytical foundations and communication. The same role remains in the CV. No promotion date is invented.
