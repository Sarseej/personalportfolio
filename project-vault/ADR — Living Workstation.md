# Living Workstation

Status: implemented; browser validation in progress.

## Decision

Preserve the desk destinations, hash routing, camera paths, focus management and quality tiers. Extend the after-hours studio with an identity-led entrance and destination-specific visual language.

The opening name contracts toward the persistent identity over a short, non-blocking sequence. Navigation is available throughout. Build mode uses cyan monitor light; Trace mode uses amber; Document mode reduces ambient exposure and lifts the paper briefly before the existing camera arrives.

Projects retain one readable workspace and progressive disclosure. Four distinct vector diagrams describe verified structure: symptoms and clinician review, reader disagreement and study design, three model branches, and physical constraints. These are explicitly conceptual illustrations, not activation data, patient records, measured stress, or experimental results.

Career uses three connected lanes for roles, projects and education. Text dates remain authoritative; spacing is not a duration scale. Mathematics Tutor → Senior Mathematics Tutor remains a single September 2023–May 2026 role with a visible promotion marker. No promotion date is invented. The CV includes the same experience.

## Reason and alternatives

The established spatial interaction works. A rebuild would risk that behavior without addressing the main weakness: presentation. Mahesh Pandit's portfolio is an interaction reference for confident identity, not a source of layout, assets, palette or typography. The studio keeps its own restrained architectural composition.

A separate screen design for every project was rejected in favor of recognizable navigation with distinct explanatory drawings. A draggable graph was rejected in favor of a complete chronological reading order.

## Accessibility and performance

All diagram explanations are semantic HTML. Decorative SVGs are hidden from assistive technology. Existing keyboard equivalents, browser history, mobile panels and WebGL fallback remain intact. Reduced motion skips identity travel, screen sweeps, paper lift and graph drawing. Animations run on entry or selection, never continuously. Geometry, lighting budget, capped resolution and demand rendering are retained. No new dependencies or full-screen bloom pass are introduced.

## Consequences

The visual layer adds no routes, deployment requirements or live services. The project illustrations must not be mistaken for real model measurements. The optional interpretability experiment remains outside this iteration. Final validation must include the rendered identity, both monitor interfaces, paper view, mobile, history and reduced motion.
